## About Me

-  **Applied ML for Code:** Exploring CodeBERT fine-tuning on defect datasets such as Defects4J and BugsInPy to identify potentially defect-prone code.
-  **Agentic AI:** Experimenting with LLM-driven agents that generate code from natural-language prompts using planning, tool calling, and iterative self-correction.
-  **Software Engineering:** Building full-stack applications with React and FastAPI, integrating APIs and AI frameworks, and exploring deployment with Vercel and Render.
-  **Security & Detection:** Developed an ML-based webcam abuse detector using Isolation Forest to flag anomalous access patterns based on access duration, user activity, application trust, resource usage, and network behavior.
